Notes!

Packing & Pengiriman

  • Kalau beli online, wajib asuransi dan minta packing kayu (biasanya nambah Rp80k–100k).
  • Kecuali kirim pakai GoSend/GrabExpress, nggak perlu packing kayu.
  • Sekalian beli antigores.
  • SAAT LAPTOP SUDAH SAMPAI WAJIB VIDEO UNBOXING.

Brand yang Dihindari

Hindari brand lokal atau brand yang bukan spesialis laptop (seperti Axioo, Advan, Tecno, Infinix). Urusan after-sales dan garansinya belum terjamin.

Harga Laptop

Harga laptop sekarang udah agak mahal, andelin voucher Shopee atau beli pas tanggal kembar aja.

Kalo ada duit beli laptop SEKARANG juga, kalau duitnya gak ada pinjol aje (financial advice btw). RAM dan storage gak bakal turun harganya karena perusahaan AI masih bakar duit, awal tahun depan harga laptop pasti lebih mahal.

Panduan Setup Laptop Windows Baru

  1. Hapus bloatware & antivirus bawaan

    • Buka Control Panel > Uninstall a program.
    • Cari dan Uninstall McAfee serta bloatware pabrik lainnya (Windows Defender bawaan sudah cukup).

  2. Debloat Windows (Chris Titus Tool)

    • Sebelum debloat pastiin Windows dan driver udah di-update ke versi terbaru (cek di Settings).
    • Klik kanan menu Start, buka Terminal (Admin) atau PowerShell (Admin).
    • Ketik/paste: iwr -useb https://christitus.com/win | iex lalu tekan Enter.
    • Di aplikasinya, masuk ke tab Tweaks > pilih preset Desktop > klik Run Tweaks.
    • Atau tonton ini aja: video panduan.

  3. Install aplikasi dasar (Ninite)

    • Buka ninite.com.
    • Centang aplikasi yang diperlukan (Discord, VLC, Zoom, Steam, dll).
    • Klik Get Your Ninite lalu jalankan installernya (otomatis install semua di background).
    • AIO Visual C++: Download "Visual C++ Redistributable Runtimes All-in-One". Ekstrak zip, jalankan file install_all.bat pakai Run as Administrator.
      Link: techpowerup.com/download/visual-c-redistributable-runtime-package-all-in-one
    • DirectX AIO: Download DirectX End-User Runtimes (June 2010) dari MajorGeeks.
      Link: majorgeeks.com/files/details/directx_end_user_runtime.html

  4. Install software wajib

    • Helium Browser: helium.computer
    • AB Download Manager: abdownloadmanager.com
    • NanaZip: Microsoft Store atau github.com/M2Team/NanaZip
    • Artcraft (pdfcraft, photocraft, wordcraft dll): getartcraft.com/apps
